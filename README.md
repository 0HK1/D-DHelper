### Descrição:
O Ajudante de RPG de Mesa é um aplicativo mobile desenvolvido para auxiliar jogadores durante sessões de RPG.
Sua principal função, atualmente, é facilitar a rolagem de dados, especialmente em campanhas mais complexas que exigem múltiplas jogadas.
Com uma interface intuitiva e prática, o aplicativo visa tornar a experiência de jogo mais ágil, organizada e imersiva, reduzindo o tempo gasto com cálculos manuais e conferência de resultados.
A princípio, o sistema foi criado para servir como uma base de estudos para a aplicação de padrões de projeto durante as aulas de Programação Orientada a Objeto Avançada na UCSal.

## Como rodar o projeto localmente (Android Studio)

1. Clone o repositório na sua máquina:

No prompt faça um clone do projeto 'git clone https://github.com/0HK1/D-DHelper.git'.

2. Clique em File > Open e selecione a pasta do projeto que você clonou.

3. Configure um dispositivo físico conectado via USB com a depuração USB ativada, ou crie um emulador Android no AVD Manager.

4. Clique no botão de run para compilar e executar o app.
